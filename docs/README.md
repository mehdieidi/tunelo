# Tunelo documentation

This directory describes the current implementation in this repository. Start with the architecture overview, then use the configuration reference when building and running the client and server.

## Guides

- [Architecture](architecture.md) — components, packet path, transports, and the overview diagram in [HTML](architecture.html) and [SVG](architecture.svg) formats.
- [Configuration and deployment](configuration.md) — build commands, flags, defaults, certificates, and WireGuard placement.
- [Development](development.md) — repository map, dependencies, and contributor commands.
- [Security notes](security.md) — transport protection and implementation limitations to account for.

The root [README](../README.md) retains the original WireGuard and Linux setup walkthrough and adds a project quick start.
